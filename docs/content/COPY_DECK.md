# Gorilla Uzbekistan — complete trilingual copy deck

- Version: 1.0
- Content freeze candidate: 2026-07-26
- Source locale: Uzbek Latin
- Parity locales: Russian, English
- Tone: direct, adult, compact, product-literate

## Copy rules

1. Copy describes product choice, flavour, verified composition, interface
   state, or visual idea. It does not promise an effect.
2. `Gorilla`, `ZERO`, and `EXTRA` retain brand casing.
3. A flavour dash is typographic: Uzbek `Mango–Kokos`, Russian
   `Манго — Кокос`, English `Mango–Coconut`.
4. Uzbek uses `o‘`, `g‘`, `sh`, `ch`; straight ASCII apostrophes are normalized
   at authoring time, not at runtime.
5. The responsible-use warning is owner/legal approved and source-linked.
   Longer privacy/terms text remains a product-behaviour draft until the final
   data processors and deployment configuration are known.
6. Strings marked `[CONDITIONAL FACT]` render only when the cited claim changes
   to `publishable`.
7. Curly-braced values are typed variables. They are not editorial placeholders:
   `{product}`, `{date}`, `{field}`.
