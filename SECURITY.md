# Security policy

## Supported version

Security fixes are applied to the current `main` branch. This portfolio concept
has no authenticated accounts, payment flow, database, or public write API.

## Report a vulnerability

Please do not disclose an exploitable issue in a public GitHub issue. Send a
private report through the security-advisory flow in this repository and
include the affected route, reproduction steps, impact, and any suggested
mitigation. Do not include real personal data or secrets.

Reports are triaged on a best-effort basis. This document is not a bug-bounty
offer and does not authorize disruptive testing, denial-of-service activity, or
access to third-party systems.
