# Contributing

This repository is public for portfolio review but is not an open-source
project. The LICENSE does not grant reuse or modification rights.

Thoughtful bug reports and accessibility findings are welcome. Before proposing
code, open a discussion describing the problem, affected viewport or assistive
technology, reproduction steps, and expected behavior. Code contributions are
accepted only by prior agreement and must pass the repository quality gates.

Do not submit brand assets, personal data, secrets, unlicensed media, or copied
design material.
